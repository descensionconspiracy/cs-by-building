# Computer science, learned by building

A self-paced Maths + CS track drawn from open curricula, shown as one page: things you already use (Maps, Shazam, Minecraft, WhatsApp...), the CS and maths inside them, playable toys, and a menu of real course projects per subject.

Open `index.html` in a browser, or visit the GitHub Pages site.
