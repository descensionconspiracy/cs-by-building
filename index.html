Ludic examples: play with the idea

Small toys, one question each. Press the buttons and the picture builds itself step by step. Each one is tied to a place you have already met the idea, with a link to read how it really happened or works.

Shazam · fingerprintsHow does a noisy five seconds find the song?

The idea. A song becomes a map of its loudest pitches over time: a constellation of dots. Shazam pairs nearby dots into tiny "hashes" (pitch, pitch, time gap) and looks each up in a table, the way you'd look a word up in an index. Matches that agree on where in the song they sit pile up into one spike. Wang 2003, the Shazam paper ↗

Before you listen: will it still find the song?

What an expert would add

Our song map is one piece; Shazam's table holds millions of songs, which is why it hashes pairs and never slides a clip along each song (the counter below shows how much work that saves). Real systems also pick peaks more carefully and tune how many partners each anchor gets.

On the track: hashing (Systems: basic hashmap), the Fourier transform (Maths), and this exact lookup trick in Algorithms.

Audio: Beethoven, Piano Sonata No. 14, 3rd movement, first 30 s. piano-midi.de via Wikimedia Commons, CC BY-SA 2.0 de.

Minecraft · seeded worldsHow can one number hold a whole world?

The idea. A seed starts a random-number generator that always gives the same sequence. Smooth random "noise" turns those numbers into hills, and finer layers add detail. Same seed, same world. Minecraft Wiki ↗

Quest: find a seed with a lake right next to a mountain.

What an expert would add

Minecraft uses 2D and 3D Perlin-style noise plus biome maps, not this single height layer, and the same seed only gives the same world within one game version, because the generator itself changes between versions.

On the track: random number generators and interpolation (Maths), arrays and hashmaps for chunks (Systems).

Quake III · a bit hackDoes the fast trick look any different?

The idea. To light a surface, a game needs each surface direction scaled to length 1, which takes 1/√x, millions of times a frame. Quake read a float's bits as an integer (roughly its logarithm), subtracted the halved bits from a magic number, then polished the guess with one Newton step. Fast inverse square root ↗

Guess first: will the fast version look different?

What an expert would add

The bits read as an integer approximate a scaled log₂ plus a bias, which is why the shift and subtract work. Credit for the trick is disputed (it predates Quake). Modern CPUs have a hardware instruction for this, so today it's history, not practice.

On the track: floating point (Systems: Sneaky NaN), Newton's method (Maths: calculus).

Angry Birds · game physicsHow does a game fly a bird along a curve?

The idea. The game never solves the curve. Every frame it nudges: speed changes by gravity, then position changes by speed. Small steps follow the true parabola (dashed); big steps drift. That's calculus done one tick at a time. Gaffer on Games ↗

Quest: hit the pig with small steps, then try with big steps.

What an expert would add

Updating speed first and position second is called semi-implicit Euler, and it's what most game engines use, because it stays stable where plain Euler blows up. Games usually also fix the step size, so the physics doesn't depend on the frame rate.

On the track: vectors and calculus (Maths), the vector class (Programming).

Photo filters · convolutionHow does a blur know what blurry means?

The idea. A filter is a tiny grid of numbers, a kernel. Slide it over every pixel, multiply by the neighbours and add up. Averaging blurs; subtracting neighbours finds edges. Kernel (image processing) ↗

Guess first: which kernel finds edges?

What an expert would add

Real blurs use a Gaussian kernel, applied as two thin 1D passes, which is far faster for big blurs. And what to do at the image's border (here: repeat the edge pixel) is a real design choice.

On the track: linear algebra (Maths), image rotate and grayscale speedup (Systems).

WhatsApp · key exchangeCan you steal the secret? Try.

The idea. Each phone keeps a secret number and sends only gsecret mod p. Each raises what it receives to its own secret, and both land on the same key. You, the listener, see both messages. Signal protocol docs ↗

Be the eavesdropper: guess phone A's secret.

What an expert would add

This is the 1976 classic version. Signal and WhatsApp use the same idea on elliptic curves (X25519), wrapped in X3DH and the Double Ratchet so keys keep changing. And key exchange alone can't stop someone sitting in the middle pretending to be each phone to the other; comparing "safety numbers" is how you catch that.

On the track: modular arithmetic and number theory (Maths), the networking subject's TLS.
